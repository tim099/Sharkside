# 🦈 Sharkside —— 方舷放置：鯊魚艦隊的無盡海

**Sharkside** ＝ shark ＋ broadside（側舷齊射）：拿 Blockside（block ＋ broadside）的海戰核心，套一個增量（放置）遊戲的外殼。
艦隊自己開船、開砲，打下來的每一格船殼就是一格 🧱 —— 升級、造船、一個海域一個海域打過去，打不動了就潛回亞特蘭提斯轉生。

**▶ 線上玩：https://tim099.github.io/Sharkside/**

（單一網頁、零外部依賴，下載整個資料夾、打開 `index.html` 也能玩；第一次載入約 3 MB，請耐心等「出航」按鈕亮起來。電腦玩最好，手機也行 —— 面板收在下面的抽屜。存檔在瀏覽器（localStorage `bsidle.v1`）。）

## 玩法

- **一個海域一場**：我方艦隊（電腦開船、開砲）對那個海域的敵艦。每艘敵艦有一個身價：打下來的格照飽和曲線領六成、擊沉領四成（降旗俘獲 ×1.5）、殉爆另加。
- **候補**：敵艦同時最多 3 艘在場，其他的是候補 —— 場上空出名額就一艘一艘進場（照核心的候補；一次只開一艘船 ⇒ 不卡）。
- **一區 10 個海域**，第 10 個是守將：加勒比淺灘 → 古代航道 → 西班牙大陸 → 北海風暴 → 幽靈海域 → 風帆巨艦 → 鐵甲時代 → 遠東艦隊 → 大漩渦 → 深淵（循環、越來越強）。打輸（或三分多鐘分不出勝負）⇒ 退一個海域練功，贏 3 場自動回去挑戰。
- **強化三選一**：第一次打下一個海域 ⇒ 跳出三張卡挑一張 —— 免費升級幾級、增益（接下來幾場）、沉船寶藏、技能冷卻歸零；史詩卡有祝福（到轉生為止、可以疊）。守將海域至少稀有。15 秒沒選就自動選 ★ 那張（設定裡可以改成一跳出來就自動選）；1～3 鍵選。
- **咬一口**：點敵艦哪裡就咬哪裡（游標滑到敵艦的船身上會變成鯊魚嘴）—— 一排牙咬下去、碎木往外噴、底下的水面濺起來；咬在水線上會進水。水面不擋：水面下的船身、打贏之後還在往下沉的船（水面下 12 m 以內）也咬得到。每一口另外領那艘身價的一點點（一艘最多三成）。名牌、空白鍵也能咬。
- **連咬**：上一口之後 1.6 秒內再咬就連下去，獎勵 ×1.15、×1.3…最多 ×3；每第 10 口暴擊（咬得大 1.6 倍、獎勵再 ×2）。右邊有計數。
- **海況**：每個海域一種（照海域號碼與轉生次數定，海域卡上寫著）—— 順風、鯊群出沒、沉船海域、海盜窩（多一艘、賞金 ×1.6）、火藥運輸線、濃霧、黃金潮汐、士氣低落……守將海域沒有。
- **黃金寶船**：不是守將的海域，每場有機率在開打後幾秒冒出一艘（沉船海域機率 ×2）：身價 ×5、幾乎不還手、打中會掉更多寶物（寶箱多），鎖定敵艦的鏡頭會換過去。
- **賞金任務**：同時三張（擊沉、俘獲、咬、撿寶、殉爆、打下新海域、拿下黃金寶船、連咬），小／中／大；做完自動領（照一場的收入 ×2／×4／×8，中、大再給隨機增益），換一張新的。面板「任務」分頁看進度。
- **漂流寶物**：敵艦被我方打中，有機率在中彈的地方漂出木桶、寶箱（格）、瓶中信（隨機增益 30 秒）。點一下撿；放著 16 秒自動撿，只拿一半。
- **升級**（格）10 種；**船塢**：擊敗過的那一型拿到藍圖就能造（藍鯊號是打過第 15 海域的禮物）；**艦隊方針** ＝ 核心的砲長（擊沉派、拆桅派、殺傷派、賭徒…）。
- **技能** 1～4：全艦齊射、鯊魚狂潮、巨齒鯊（一條大鯊魚游過畫面，每艘敵艦咬一大口）、緊急搶修。
- **鏡頭**（預設鎖定敵艦）：跟著一艘敵艦、沒在摸就慢慢繞；那艘降旗或沉了，再看幾秒換離它最近的下一艘。咬哪艘就換看哪艘，Tab 換下一艘，C 換鏡頭（鎖定敵艦／自動運鏡／看旗艦／自己轉）。
- **潛回亞特蘭提斯（轉生）**：第 25 海域起。帶走三叉戟碎片（累計每顆收入 +10%），買深海科技（轉生也留著）。
- **離線**：關掉、切走的時間照最近幾場的收入速度 × 離線效率（25% 起）補給妳。

## 強度怎麼換成模擬

數字可以一直變大，可是模擬裡的東西都夾在範圍內 ⇒ 戰局永遠是正常的物理：

- 火力比 `atkR` ＝ 我方火力 ÷ 海域強度：敵艦船殼硬度、我方每發傷害、砲彈打出來的洞（開火那一刻改那一顆，核心的 `rptShot`）。
- 船堅比 `defR` 反過來作用在我方船殼與敵方砲彈。增益照樣乘在這些東西上（裝填、硬度、航速每一格重乘）。
- 放置模式的底：敵艦硬度 ×0.15、進水 ×6、抽水 ×0.4（不然兩艘小船對轟五分鐘還分不出勝負）。
- 常數都在 `src/js/10_data.js` 的 `BAL`；調手感只改那一支。

## 建置

```bash
python -I build.py --core <Blockside 的工作副本>           # 套頁 ⇒ index.html；船檔、海圖、圖示照抄
python -I build.py --core <Blockside 的工作副本> --check   # 只比：跟那一份核心、src/ 對不上 ⇒ exit 1
```

- 核心要有外殼 API（`src/js/91_shellapi.js`）；那一份要先建好（Blockside 的 `python -I src/admin.py build`）。
- 改了 `src/` 就重建；核心換了也重建（船檔清單、雜湊跟著換）。
- ⛔ 外殼的 js 裡不要有「</」：套頁時會換成「<\/」，正規表示式 `/</g` 就壞了（寫成 `/[<]/g`）。

## 部署（GitHub Pages）

已經開好：Settings → Pages → Build and deployment 是 **Deploy from a branch**，`main`、`/ (root)` ⇒ 推上 `main` 一兩分鐘後線上那一份就換了。`.nojekyll` 讓 Pages 原樣放檔（不跑 Jekyll）。

## 海圖

海域可以帶海圖（`10_data.js` 的 `map`／`site`；Blockside 的 `maps/<名字>`，用 Blocksail 的 `tools/export_chunks.cjs` 匯出）：托爾圖加海峽、薩拉米斯海峽、漢普頓錨地、羅弗敦漩渦海峽。核心開機時讀 `?map=`，換到別張 ⇒ 存檔、重新載入這一頁、接著打。

## 測

- 本機：`python -m http.server 8813 --bind 127.0.0.1` 再開 http://127.0.0.1:8813/。
- 內建瀏覽器的窗格藏著的時候 `requestAnimationFrame` 不跑 ⇒ 模擬停住：主控台 `requestAnimationFrame = cb => setTimeout(() => cb(performance.now()), 33)`，再截一張圖踢一下；CSS 動畫、轉場在藏著的窗格裡也不會走（要看演出 ⇒ 把動畫停在某一刻再截圖）。
- `BSI`（外殼）、`BS_SHELL.core`（核心 API）在主控台都摸得到；`BSI.S.speed = 4` 快轉、`BSI.BAL.lootP = 1` 一直掉寶、`BSI.perkRoll(10, true, 10000)` 叫出三選一。
